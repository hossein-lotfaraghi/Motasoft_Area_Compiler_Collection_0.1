Motasoft Area Compiler Collection (MACC)

Usage:
  macc [options] file.cs...

Options:
  -o <file>       Specify output executable
  -O              Enable optimization
  -O1             Enable optimization level 1
  -O2             Enable optimization level 2
  -O3             Enable optimization level 3
  -g              Generate debug information
  -h, --help      Display this help
  -v, --version   Display compiler version

Examples:
  macc hello.cs -o hello
  macc main.cs math.cs -o app
  macc -O2 main.cs -o app
  macc -g main.cs -o debug
